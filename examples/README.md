# Примеры работы сервера

Все файлы в этой папке получил 11 ноября 2026 двумя запусками консольного клиента. Модель `deepseek/deepseek-v4.1-flash` через OpenRouter, запрос из задания:

```bash
python clients/console_client.py --file data/sales_data.csv "Проанализируй продажи, построй графики и дай рекомендации"
```

```bash
python clients/console_client.py --file data/orders_dirty.xlsx "Проанализируй продажи, построй графики и дай рекомендации"
```

## Что здесь лежит

| Папка | Что в ней |
|---|---|
| `report-sales/` | Отчёт по `data/sales_data.csv`: `report.md`, тот же отчёт одним файлом `report.pdf` и пять графиков |
| `report-orders/` | Отчёт по «грязной» выгрузке `data/orders_dirty.xlsx`: `report.md`, `report.pdf` и четыре графика |
| `console/` | Журнал вызовов первого запуска `console-log.txt` и итоговый ответ модели `answer.md` |
| `screenshots/` | Скриншоты тех же запросов в Claude Desktop, claude.ai и Telegram |

Отчёты собрал инструмент `save_report`. Цифры и графики в них посчитал сервер, выводы и рекомендации написала модель по этим цифрам.

## Что видно в журнале

Журнал `console/console-log.txt` это строки JSON: по одной на каждый вызов инструмента. По нему видно порядок этапов и цену запуска.

| Запуск | Запросов к модели | Вызовов инструментов | Статус | Стоимость |
|---|---|---|---|---|
| `sales_data.csv` | 8 | 11 | ok | 0,006 $ |
| `orders_dirty.xlsx` | 8 | 10 | ok | 0,003 $ |

Числа взяты из последней строки журнала каждого запуска (поля `steps`, `status`, `usage.cost`). Журнал второго запуска в репозиторий не клал.

## Что проверить в отчёте по `sales_data.csv`

В данные заложены три закономерности (генератор `data/generate_data.py`): декабрьский пик, быстрый рост Казани и убыточные «Готовые обеды». В `report-sales/report.md` названы все три.
