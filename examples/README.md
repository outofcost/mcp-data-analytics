# Примеры работы сервера

Все файлы в этой папке получил 11 ноября 2026 двумя запусками консольного клиента. Модель `deepseek/deepseek-v4.1-flash` через OpenRouter, запрос из задания:

```bash
python clients/console_client.py --file data/sales_data.csv "Проанализируй продажи, построй графики и дай рекомендации"
```

```bash
python clients/console_client.py --file data/orders_dirty.xlsx "Проанализируй продажи, построй графики и дай рекомендации"
```

## Что здесь лежит

| Папка | Что в ней |
|---|---|
| `report-sales/` | Отчёт по `data/sales_data.csv`: `report.md`, тот же отчёт одним файлом `report.pdf`, четыре графика и картинка первой страницы PDF |
| `report-orders/` | Отчёт по «грязной» выгрузке `data/orders_dirty.xlsx`: `report.md`, `report.pdf` и шесть графиков |
| `console/` | Журнал вызовов первого запуска `console-log.txt` и короткий ответ `answer.md`, который сервер собрал для чата |
| `screenshots/` | Скриншоты запросов в Claude Desktop, claude.ai и Telegram |

Отчёты собрал инструмент `save_report`. Цифры и графики в них посчитал сервер, выводы и рекомендации написала модель по этим цифрам.

## Что видно в журнале

Журнал `console/console-log.txt` это строки JSON: по одной на каждый вызов инструмента. По нему видно порядок этапов и цену запуска.

| Запуск | Запросов к модели | Вызовов инструментов | Статус | Стоимость |
|---|---|---|---|---|
| `sales_data.csv` | 8 | 10 | ok | 0,0026 $ |
| `orders_dirty.xlsx` | 8 | 13 | ok | 0,0025 $ |

Числа взяты из последней строки журнала каждого запуска (поля `steps`, `status`, `usage.cost`). Журнал второго запуска в репозиторий не клал.

## Как я проверял клиентов

Проверки из таблицы клиентов в README делал 11 ноября 2026 на одной машине с macOS. В тот же день сервер и бот запускались на Ubuntu 22.04 с Python 3.12.16: бот разобрал `sales_data.csv` (8 запросов к модели, статус ok, 5 графиков, отчёт в PDF), сервер по HTTP ответил MCP-клиенту через туннель. После обновления сервера бот на нём разобрал и файл Excel `orders_dirty.xlsx`. Тесты на Linux не запускались. В claude.ai запрос прошёл на двух файлах: `sales_data.csv` и `orders_dirty.xlsx`. В обычном чате Claude Desktop сервер находится поиском по описаниям инструментов. Поэтому описания написаны словами пользователя, а `list_data_files` называет файлы папки прямо в описании.

ChatGPT и Codex подключались только к пробному серверу с одним инструментом, который я писал до основного кода. ChatGPT график из ответа инструмента не показал. С настоящим сервером я их не проверял.

Автооткрытие PDF в Claude Desktop проверено запуском сервера с переменной `ANALYTICS_OPEN_REPORT=1` вне приложения. Внутри приложения после добавления этой строки в конфиг я его не проверял.

## Что проверить в отчёте по `sales_data.csv`

В данные заложены три закономерности (генератор `data/generate_data.py`): декабрьский пик, быстрый рост Казани и убыточные «Готовые обеды». В `report-sales/report.md` названы все три: убыток обедов и пик в выводах, рост Казани в рекомендациях.
