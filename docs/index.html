MCP-сервер для анализа таблиц

Сервер по протоколу MCP загружает таблицу CSV или Excel, чистит данные и строит графики.

Подключите его к своему ИИ-помощнику: в ответ на запрос в чате придут графики, выводы с рекомендациями и отчёт в PDF.

Результат можно посмотреть, ничего не подключая: пример отчёта по sales_data.csv лежит в репозитории. Ссылку на PDF в ответе сервера браузер открывает через страницу-предупреждение ngrok: на ней нужно нажать кнопку продолжения.

Подключите сервер по адресу

https://affluent-grant-finalize.ngrok-free.dev/mcp

Добавьте сервер в настройках до начала чата

Из уже идущего чата помощник сервер себе не добавит.

  • В Claude откройте Settings, затем Connectors и нажмите Add custom connector. Назовите сервер analytics, вставьте адрес и выберите вход «No sign in».
  • В Cursor на компьютере вставьте блок ниже в файл ~/.cursor/mcp.json. Если сервер не появился в списке, перезапустите Cursor.
  • Для облачного агента Cursor добавьте сервер в списке MCP на cursor.com/agents, тип HTTP, и запустите нового агента.
  • В ChatGPT добавьте в настройках свой MCP-сервер по этому адресу, без аутентификации.
{
  "mcpServers": {
    "analytics": {
      "url": "https://affluent-grant-finalize.ngrok-free.dev/mcp"
    }
  }
}

Шаги для Claude я прошёл на этом сервере. Шаги для Cursor сверил с его документацией, шаг для ChatGPT не проверял.

Claude Desktop, консольный клиент через API и свой Telegram-бот подключаются локально: команды и конфиг лежат в README.

В новом чате отправьте запрос

Проанализируй через analytics продажи из файла sales_data.csv, построй графики и дай рекомендации. Файл лежит на сервере, прикладывать его не нужно.

Если сервера нет в списке инструментов

Это запасной путь для помощника с доступом в сеть: он обращается к серверу напрямую.

MCP-сервера analytics у тебя в инструментах нет, из этой сессии его не добавить. Работай с ним напрямую: отправляй POST с JSON-RPC на https://affluent-grant-finalize.ngrok-free.dev/mcp, заголовки Content-Type: application/json и Accept: application/json, text/event-stream. Сначала initialize, потом tools/list и tools/call. Ключ не нужен.
Начни с load_data(file_path="sales_data.csv") и выполняй поле next_step из каждого ответа, пока анализ не завершится. В конце покажи chat_summary как есть и ссылку на отчёт.

Или напишите боту в Telegram

Пришлите боту @test_vkusvillmcpKK_bot файл CSV или Excel, запрос напишите в подписи к файлу. Примерно через минуту придут альбом графиков, текст выводов и отчёт в PDF.

Какие инструменты видит модель

Порядок этапов задаёт сервер: каждый ответ инструмента называет следующий шаг.

  • list_data_filesФайлы с данными на сервере

    Показывает файлы с данными (CSV, Excel) в папке data/ сервера.

  • load_dataЗагрузить данные из CSV или Excel

    Загружает таблицу из файла CSV или Excel.

  • describe_dataБазовая статистика

    Считает базовую статистику по таблице.

  • clean_dataОчистить данные

    Чистит таблицу и сообщает, что именно сделано, с числами.

  • suggest_chartsПодобрать графики

    Подбирает графики по типам колонок и возвращает готовые вызовы.

  • plot_trendГрафик тренда

    Строит график тренда: сумма показателя по периодам времени.

  • plot_distributionГрафик распределения

    Строит распределение: гистограмму числа или столбцы по категории.

  • correlation_analysisМатрица корреляций

    Строит матрицу корреляций числовых колонок (тепловая карта).

  • abc_analysisABC-анализ

    Делит значения колонки на группы A, B, C по вкладу в сумму.

  • collect_findingsЦифры для выводов

    Считает цифры, на которых строятся выводы и рекомендации.

  • save_reportСохранить отчёт

    Собирает отчёт и сохраняет его в двух видах: Markdown и PDF.

Что стоит знать заранее

У адреса нет входа: это демо-режим для показа. Память сервера общая для всех, кто подключился, а бот отправляет файл и запрос провайдеру языковой модели. Закрытые данные присылать не стоит.

Код, README и примеры отчётов лежат в репозитории github.com/outofcost/mcp-data-analytics.
