MCP-сервер для анализа таблиц

Сервер по протоколу MCP загружает таблицу CSV или Excel, чистит данные и строит графики.

Подключите его к своему ИИ-помощнику: в ответ на запрос в чате придут графики, выводы с рекомендациями и отчёт в PDF.

Отправьте помощнику готовый запрос

Подключись к MCP-серверу для анализа таблиц по адресу https://affluent-grant-finalize.ngrok-free.dev/mcp.
Если сам подключиться не можешь, объясни по шагам, где вписать этот адрес в настройках.
Потом через этот сервер выполни запрос: «Проанализируй продажи из файла sales_data.csv, построй графики и дай рекомендации». Файл лежит на сервере, прикладывать его не нужно.

Как подключить в Claude

  1. В claude.ai откройте Settings, затем Connectors и нажмите Add custom connector.
  2. Вставьте адрес сервера и выберите вход «No sign in».
  3. В новом чате напишите: «Проанализируй продажи из файла sales_data.csv, построй графики и дай рекомендации». Файл прикладывать не нужно: он лежит на сервере.

Claude Desktop, консольный клиент через API и свой Telegram-бот подключаются локально: команды и конфиг лежат в README.

Какие инструменты видит модель

Порядок этапов задаёт сервер: каждый ответ инструмента называет следующий шаг.

  • list_data_filesФайлы с данными на сервере

    Показывает файлы с данными (CSV, Excel) в папке data/ сервера.

  • load_dataЗагрузить данные из CSV или Excel

    Загружает таблицу из файла CSV или Excel.

  • describe_dataБазовая статистика

    Считает базовую статистику по таблице.

  • clean_dataОчистить данные

    Чистит таблицу и сообщает, что именно сделано, с числами.

  • suggest_chartsПодобрать графики

    Подбирает графики по типам колонок и возвращает готовые вызовы.

  • plot_trendГрафик тренда

    Строит график тренда: сумма показателя по периодам времени.

  • plot_distributionГрафик распределения

    Строит распределение: гистограмму числа или столбцы по категории.

  • correlation_analysisМатрица корреляций

    Строит матрицу корреляций числовых колонок (тепловая карта).

  • abc_analysisABC-анализ

    Делит значения колонки на группы A, B, C по вкладу в сумму.

  • collect_findingsЦифры для выводов

    Считает цифры, на которых строятся выводы и рекомендации.

  • save_reportСохранить отчёт

    Собирает отчёт и сохраняет его в двух видах: Markdown и PDF.

Что стоит знать заранее

У адреса нет входа: это демо-режим для показа. Память сервера общая для всех, кто подключился, а бот отправляет файл и запрос провайдеру языковой модели. Закрытые данные присылать не стоит.

Код, README и примеры отчётов лежат в репозитории github.com/outofcost/mcp-data-analytics.
